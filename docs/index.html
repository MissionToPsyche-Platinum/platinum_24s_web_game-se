Welcome to Mission to Psyche!

Objective: Navigate Psyche to its asteroid destination by solving challenging puzzles!

Each level will present you with a different puzzle. Solve each one to move Psyche closer to its destination.

After completing each puzzle, you will be presented with a fact about the real Psyche mission!

Good luck astronaut! How much can you learn about the Psyche mission?

Scoring

Your leaderboard score is your total mission time. Finish all 5 puzzles as quickly as you can — the fastest complete runs rank highest.

  • The timer runs while you are solving a puzzle.
  • The timer pauses after each solve (mission fact) and while Puzzle Help is open.
  • Challenge mode uses harder puzzles. Ranking is still by fastest time.
