Welcome to Mission to Pysche!

Objective: Navigate Psyche to its asteroid destination by solving challenging puzzles!

Each level will present you with a different puzzle. Solve each one to move Psyche closer to its destination.

After completing each puzzle, you will be presented with a fact about the real Psyche mission!

Each run will be timed, so try to complete the game as quickly as possible to earn the top score for the leaderboard!

Good luck astronaut! How much can you learn about the Psyche mission?

Thank you for trying out Mission to Psyche!
